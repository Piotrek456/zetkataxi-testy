# Zetka Taxi — testy APK

Automatyczny test aplikacji Zetka Taxi (kierowca, klient, flota) w emulatorze Androida:
instalacja, uruchomienie, zabicie procesu strony (WebView) i sprawdzenie, czy aplikacja przetrwała.

Repozytorium zawiera wyłącznie skrypt testowy. Pliki APK są pobierane z publicznej strony
https://zielona-taxi.netlify.app/pobierz/.
